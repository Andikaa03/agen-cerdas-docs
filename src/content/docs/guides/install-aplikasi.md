---
title: Install sebagai Aplikasi
description: Cara memasang Agen Cerdas sebagai aplikasi di Chrome atau Edge.
---

Agen Cerdas bisa dipasang seperti aplikasi di laptop/PC melalui fitur install app di Chrome atau Edge. Setelah terpasang, aplikasi bisa dibuka dari desktop, dock, taskbar, atau launcher tanpa perlu mengetik alamat website setiap kali.

## Syarat

- Gunakan browser Chrome atau Edge versi terbaru.
- Buka domain aplikasi Agen Cerdas yang biasa dipakai.
- Pastikan koneksi internet aktif saat pertama kali memasang.

## Cara Install di Chrome Desktop

1. Buka Agen Cerdas di Chrome.
2. Login seperti biasa.
3. Lihat bagian kanan address bar.
4. Klik ikon install jika muncul.
5. Pilih **Install**.
6. Setelah selesai, Agen Cerdas akan terbuka sebagai jendela aplikasi sendiri.

Jika ikon install tidak muncul:

1. Klik menu titik tiga di kanan atas Chrome.
2. Pilih **Save and share** atau **More tools**.
3. Klik **Install Agen Cerdas** atau **Create shortcut**.
4. Centang **Open as window** jika tersedia.
5. Klik **Create** atau **Install**.

## Cara Install di Edge

1. Buka Agen Cerdas di Edge.
2. Klik menu titik tiga.
3. Pilih **Apps**.
4. Klik **Install this site as an app**.
5. Konfirmasi nama aplikasi, lalu klik **Install**.

## Setelah Terpasang

- Aplikasi tetap memakai akun login yang sama seperti browser.
- Printer Bluetooth tetap membutuhkan izin dari browser/aplikasi.
- Jika aplikasi terlihat belum update, tutup semua jendela Agen Cerdas lalu buka lagi.

> [!NOTE]
> Aplikasi ini tetap berbasis web. Data transaksi tersimpan di server Agen Cerdas, bukan hanya di komputer yang dipakai.
