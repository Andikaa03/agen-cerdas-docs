---
title: Dashboard Laporan
description: Lihat performa transaksi agen hari ini dan bulan ini.
---

Menu **Dashboard Laporan** menampilkan performa khusus transaksi agen. Halaman ini fokus ke omzet, pendapatan, admin provider, hutang, jumlah transaksi, grafik, dan rekap per tipe transaksi.

![Laporan Pendapatan](/images/laporan-pendapatan.png)

## 1. Ringkasan Utama

Bagian atas menampilkan ringkasan bulan ini seperti:

- **Omzet Bulan Ini**
- **Pendapatan Bersih**
- **Total Transaksi**

Persentase kartu dibandingkan dengan bulan lalu.

## 2. Transaksi Hari Ini

Bagian ini merangkum transaksi agen hari ini:

- Omzet
- Pendapatan kotor
- Admin bank/provider
- Pendapatan bersih
- Hutang belum lunas
- Total transaksi

Perbandingan di kartu harian memakai data kemarin.

## 3. Transaksi Bulan Ini

Bagian bulan ini menampilkan metrik yang sama, tetapi untuk bulan berjalan. Perbandingannya memakai bulan lalu.

## 4. Grafik dan Rekap Tipe

Grafik membantu melihat perkembangan omzet, pendapatan kotor, pendapatan bersih, dan admin provider dari hari ke hari.

Rekap per tipe transaksi menunjukkan tipe transaksi paling banyak dipakai, total pokok, jumlah transaksi, dan profit.
