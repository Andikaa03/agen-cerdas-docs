Menu **Langganan Paket** dipakai owner untuk melihat status paket, masa aktif, invoice pembayaran, dan kuota cabang/user.

![Halaman Langganan](/images/langganan-paket.png)

## 1. Cek Sisa Masa Aktif
Cuma owner yang bisa membuka menu ini. Di halaman **Langganan Paket**, kamu bisa melihat:
- **Paket Apa yang Dipake**: Misalnya lagi pake Paket Pro atau masih nyoba Gratis (Trial).
- **Kapan Habisnya**: Ada tanggal kadaluwarsanya yang jelas dan hitung mundur sisa harinya, biar kamu nggak kaget.
- **Batasan Kuota**: maksimal jumlah cabang dan user aktif sesuai paket.

## 2. Cara Perpanjang / Upgrade ke Pro
Kalo masa trial udah mau abis atau kamu mau perpanjang langganan bulanan, gini caranya:
1. Klik menu **Langganan Paket**.
2. Klik tombol **Upgrade ke Pro** (atau Perpanjang).
3. Aplikasi membuat invoice pembayaran.
4. Di bagian bawah layar, bakal muncul instruksi pembayaran lengkap:
   - **Nomor Rekening BCA**: Kalo mau transfer langsung pake M-Banking.
   - **Barcode QRIS**: Kalo mau scan bayar pake GoPay/Dana/OVO (Tinggal klik "Bayar dengan QRIS" buat buka gambarnya).
5. Kalo udah transfer, klik tombol hijau **"Konfirmasi Pembayaran"**. 
6. Kamu akan diarahkan ke WhatsApp admin untuk mengirim bukti transfer. Setelah admin menyetujui pembayaran, masa aktif paket akan diperbarui.

> [!CAUTION]
> **Aduh, Kalo Terlanjur Expired Gimana?**
> Tenang aja! Data transaksi kamu **NGGAK BAKAL DIHAPUS**. Semuanya aman. Cuma, layar jualan sama kasirnya bakal "dikunci" sementara sampe admin acc perpanjangan kamu. Kalo udah dibayar, otomatis kebuka lagi deh semuanya!

## 3. Status Langganan

Status yang umum muncul:

- **Trial**: masa coba gratis masih aktif.
- **Aktif**: paket berbayar sedang berjalan.
- **Expired**: masa aktif habis dan beberapa fitur terkunci.
- **Suspended**: akun dihentikan sementara oleh admin.

## 4. Kuota Cabang dan User

Setiap paket bisa memiliki batas jumlah cabang dan user aktif. Jika kuota habis:

- Owner tidak bisa menambah cabang baru.
- Owner tidak bisa menambah user baru.
- Data lama tetap tersimpan.

Jika butuh tambahan, hubungi admin untuk upgrade atau penyesuaian paket.

## 5. Riwayat Invoice

Gunakan riwayat invoice untuk melihat pembayaran yang pernah dibuat, status pembayaran, dan masa aktif paket. Simpan bukti pembayaran sampai status invoice disetujui admin.
